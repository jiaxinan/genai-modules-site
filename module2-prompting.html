Module 2 of 6

Prompting Techniques as Options to Test

Four research-backed approaches (direct instruction, few-shot, decomposition, critique & revision) treated as hypotheses, not recipes.

⏱ ≈ 2.5 min in lecturePracticeResearch

🎯Learning goals

  • Name four accessible prompting approaches and when each might help.
  • Rewrite a vague prompt so the response becomes something you can evaluate.
  • Treat a published technique as something to test, not a guaranteed solution.

🧰Four approaches to try

ApproachWhat you can try
Direct instructionSpecify the task, intended audience, and output format.
Few-shot promptingProvide examples of the kind of answer you want.
Task decompositionDivide a complex task into smaller, assessable parts.
Critique and revisionAsk for a revision against explicit criteria, then check it yourself.

The Prompt Report is a systematic survey that organizes a large body of prompting research, including 58 text-based prompting techniques. It also discusses prompt sensitivity: a technique's usefulness depends on the task and the model.

✏️From vague to specific

Initial prompt

Explain misinformation.

More specific prompt

Explain misinformation to a first-year informatics student in 150 words. Distinguish it from disinformation. Include a clearly labeled hypothetical example and identify one case where determining intent would be difficult.

💬Think about it

What could we evaluate in the second response that the first prompt leaves unspecified?

Expected answers
  • Audience (first-year informatics student)
  • Length (150 words)
  • Conceptual distinction (misinformation vs. disinformation)
  • A labeled hypothetical example
  • Treatment of uncertainty (when intent is hard to determine)

🔗Resources
